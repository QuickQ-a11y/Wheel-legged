# Codex文档 目录说明

## 这里放什么

**两块板共享的文档** + **一条按时间排的交接流**。板专属的文档在各板自己的
`Codex文档/` 下（目前只有 `Chassis/Codex文档/`）。

| 文件 | 性质 |
|---|---|
| `代码风格要求.md` | 共享。完整版风格规范，写业务代码前必读。精简版在仓库根 `CLAUDE.md`，自动加载 |
| `Windows环境搭建指南.md` | 共享 |
| `handoff-*.md` | 交接流，见下 |

## 交接文档约定

**一条流，不按板分。** 交接的价值在时间线，分两处就要拼时间线；而且跨板会话
（板间协议、整仓重组、力矩标度排查）在按板分的方案里无处安放。

每篇开头注明作用范围：

```markdown
# 交接文档 2026-09-21 12:00
> 范围：跨板 | 上一份：handoff-2026-09-10-0300.md
```

范围取 `底盘` / `云台` / `跨板` 三者之一。

## ⚠ 读旧文档时注意

**2026-09-21 之前的 handoff 均为底盘范围**，当时仓库还没有分 `Chassis/` 和 `Gimbal/`，
所以它们里面的相对路径是按旧布局写的：

- 文中的 `Codex文档/实机调试检查清单.md`、`HERO_LEG参考要点.md`、
  `Qi-Q26方案分析与TinyMPC可行性.md`、`TinyMPC学习路线.md`
  —— 现在实际在 **`Chassis/Codex文档/`** 下
- 文中的 `User_File/...`、`Tests/...`、`CMakeLists.txt`
  —— 现在实际在 **`Chassis/`** 下

这些是历史快照，**不回填修正**（改了反而看不出当时的真实状态）。
